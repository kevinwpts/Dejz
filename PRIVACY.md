# Integritetspolicy för Dayspend

Senast uppdaterad: 2026-03-16

Din integritet är viktig för oss. Denna policy beskriver hur vi hanterar din data.

## 1. Insamlad information
Vi samlar in information som du aktivt matar in i appen (utgifter, inkomster, sparmål). Vi använder Supabase för autentisering och datalagring.

## 2. Användning av data
Din data används endast för att tillhandahålla tjänsten Dayspend. Vi säljer inte din data till tredje part.

## 3. Säkerhet
Vi vidtar rimliga åtgärder för att skydda din data.

## 4. Kontakt
För frågor om din integritet, kontakta oss via support-e-posten i appen.
