# Användarvillkor för Dayspend

Senast uppdaterad: 2026-03-16

Välkommen till Dayspend. Genom att använda vår tjänst godkänner du följande villkor.

## 1. Användning av tjänsten
Dayspend tillhandahålls "i befintligt skick". Vi ansvarar inte för eventuella ekonomiska förluster som kan uppstå vid användning av appen.

## 2. Användarkonto
Du ansvarar för att hålla dina inloggningsuppgifter säkra.

## 3. Ändringar i villkor
Vi kan komma att uppdatera dessa villkor. Genom att fortsätta använda appen godkänner du de uppdaterade villkoren.
