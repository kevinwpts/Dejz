# Annonser

| Fil | Format | Används till |
| :--- | :--- | :--- |
| `dejz-annons-9x16.png` | 1080 × 1920 | TikTok, Instagram Reels, Stories |
| `dejz-annons-4x5.png` | 1080 × 1350 | Instagram- och Facebook-flödet |

Bilderna skapas från `ad.html`. Ändra texten där och kör om skärmbilden om du vill göra nya varianter.

**Länkar med spårning.** Använd en egen länk per kanal, så att du ser i väntelistan var folk kommer ifrån:
- TikTok: `https://dejz.se/?utm_source=tiktok`
- Instagram: `https://dejz.se/?utm_source=instagram`
- Facebook/Meta-annonser: `https://dejz.se/?utm_source=meta`
